# โน้ตย่อย: Event Storming

เพิ่มไฟล์เมื่อมีแนวคิดเฉพาะประเด็นที่ควรอธิบายและเชื่อมโยงแยกจากภาพรวม ตั้งชื่อไฟล์ตามใจความของโน้ต

โน้ตแต่ละไฟล์ควรมี:

- ชื่อเรื่องที่สื่อข้อคิดหรือแนวคิดหลัก
- คำอธิบายที่เข้าใจได้เมื่ออ่านแยกจากบริบท
- แหล่งอ้างอิงที่รองรับเนื้อหา
- ลิงก์ไปยังโน้ตและหัวข้อที่เกี่ยวข้อง พร้อมบอกความสัมพันธ์เมื่อจำเป็น

ยังไม่มีโน้ตย่อย
