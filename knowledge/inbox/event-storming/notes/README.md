# โน้ตย่อย: Event Storming

เพิ่มไฟล์เมื่อมีแนวคิดเฉพาะประเด็นที่ควรอธิบายและเชื่อมโยงแยกจากภาพรวม ตั้งชื่อไฟล์ตามใจความของโน้ต

ใช้ template เป็นจุดเริ่มต้นได้ แต่ไม่จำเป็นต้องคงหัวข้อหรือรูปแบบเดียวกันทุกไฟล์ โน้ตควรมีข้อมูล metadata สำหรับระบุชนิดและสถานะ ส่วนเนื้อหาเลือกจัดรูปแบบตามแนวคิด เช่น คำอธิบาย ตาราง ตัวอย่าง หรือขั้นตอน

แนวทาง:

- เขียนให้เข้าใจได้เมื่ออ่านแยกจากบริบท
- ใส่แหล่งอ้างอิงเมื่อมีข้อกล่าวอ้างที่ต้องตรวจสอบ
- เชื่อมโยงโน้ตหรือหัวข้อที่เกี่ยวข้องเมื่อช่วยให้ค้นต่อหรือเข้าใจความสัมพันธ์
- เพิ่ม `tags` เฉพาะเมื่อช่วยจัดกลุ่มหรือค้นข้ามหัวข้อ และใช้ชื่อ tag ที่มีอยู่ก่อนสร้างชื่อใหม่

ยังไม่มีโน้ตย่อย
