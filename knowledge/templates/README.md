# วิธีใช้ template

โฟลเดอร์นี้รวมแบบร่าง Markdown สำหรับชนิดเอกสารที่ใช้อยู่ใน HACLS และอยู่ภายใน Obsidian vault (`knowledge/`) ดูรหัสและเลือกแบบร่างจาก [ดัชนี template](index.md)

ใน Obsidian ตั้ง **Settings → Core plugins → Templates → Template folder location** เป็น `templates` ซึ่งเป็น path ที่อิงจากราก vault การตั้งค่านี้ถูกบันทึกไว้ใน `.obsidian/templates.json` แล้ว

## วิธีเริ่มเอกสาร

1. เลือกรหัสชนิดเอกสารจาก `templates/index.md` ตามวัตถุประสงค์ของเอกสาร
2. คัดลอกไฟล์ template ไปยังตำแหน่งปลายทางที่ระบุในดัชนี แล้วตั้งชื่อไฟล์ให้สื่อความหมาย
3. แทนที่ข้อความตัวอย่าง แล้วจัดเนื้อหาในรูปแบบที่เหมาะกับเอกสารนั้น
4. เก็บรหัสชนิดไว้ใน metadata หรือส่วนหัวของเอกสารตามที่ template กำหนด เพื่ออ้างกลับมายังรายการนี้ได้
5. เพิ่มลิงก์จากดัชนีหัวข้อหรือดัชนี repository ที่เกี่ยวข้อง หากเอกสารนั้นควรถูกค้นพบจากที่นั่น

รหัสในดัชนีระบุ **ชนิดเอกสาร** ไม่ใช่รหัสเฉพาะของเอกสารแต่ละชิ้น และการใช้ template ไม่ได้ทำให้เนื้อหาผ่านการตรวจหรือเลื่อนสถานะโดยอัตโนมัติ ความรู้ใน `knowledge/inbox/` ยังคงเป็นข้อเสนอที่ยังไม่ผ่านการตรวจ จนกว่าเจ้าของโครงการจะอนุมัติให้เป็น `validated` หรือ `canonical`

สำหรับโน้ตความรู้ สามารถเพิ่ม `tags` ใน metadata เมื่อช่วยจัดกลุ่มหรือค้นข้ามหัวข้อ ไม่จำเป็นต้องใส่ทุกโน้ต และควรใช้ชื่อ tag ที่มีอยู่ก่อนสร้างชื่อใหม่ ลิงก์ไปยังโน้ตหรือหัวข้อที่เกี่ยวข้องให้ใส่ในเนื้อหาเมื่อมีความสัมพันธ์ที่เป็นประโยชน์

## การเพิ่มหรือแก้ template

- ตรวจว่ามีเอกสารชนิดนั้นใช้อยู่หรือมีความจำเป็นชัดเจนก่อนเพิ่ม template ใหม่
- ใช้รหัสชนิดที่ไม่ซ้ำ พร้อมเพิ่มคำอธิบาย ตำแหน่งปลายทาง และลิงก์ template ใน `templates/index.md`
- เขียนเป็นคำถามหรือ placeholder แทนการเติมข้อเท็จจริงที่ยังไม่ได้ตรวจสอบ
- ระบุแหล่งข้อมูลและสถานะการตรวจเมื่อ template ใช้กับความรู้หรือผลวิจัย
